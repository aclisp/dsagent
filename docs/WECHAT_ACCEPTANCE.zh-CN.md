# 微信首版真实验收

状态：2026-11-10 完成主要真实微信验收；网络、存储和媒体错误等故障注入由自动化测试补充覆盖。

使用独立测试 workspace 和 DSCode home，避免与运行中的正式实例共用状态目录。先构建并通过 `pnpm check`，再进行手机侧联调。测试目录应由本次验收新建；已有 `.env`、绑定凭据或个人状态未经批准不得修改。

1. 在测试实例执行 `dscode channels login wechat`；扫码并完成可能出现的数字验证，确认凭据只保存到测试 home。重启服务后微信与 HTTP 均可用。
2. 发一条文本任务，确认进入共享 Session，微信显示输入状态，结束后收到结果并取消输入状态。
3. 发语音，验证有转写时正常处理；无转写时提示改发文字。
4. 连续发送两张图片，再发说明；应产生一个包含两张图和说明的 Turn。文件和说明同样验证。
5. 用不可用的新附件或自动化故障注入验证整批拒绝；Agent 未开始工作，微信收到重发提示。
6. 要求生成图片与文本文件，用行内路径引用交付；微信收到文字和对应文件。验证超限文件有提示。
7. 引用此前的文本、图片和文件继续提问；重启后再次引用，应恢复保存的正文与可用附件。未知引用明确标注缺失。
8. 执行长任务时再发消息，后者收到 busy；原任务继续，最终回复使用原消息上下文。其他已配置 Provider 和 Web UI 也遵循共享 busy 状态。
9. 验证任务失败和主动中止：输入状态停止，微信收到简短通知。
10. 从微信创建 source 定时任务，等待执行并收到主动回投；重启后再验证已保存 token 的投递尝试。失效或投递失败时，共享历史仍保存结果。
11. 用自动化注入配合受控进程重启，验证未提交请求恢复，已提交请求只保留中断记录；已完成但未发完的回复和文件不在重启后自动补投。
12. 注入一次文件发送临时错误，确认只重试未确认文件，已发送文字与文件不重复。永久错误或耗尽时收到简短说明。

记录测试日期、部署版本、手机微信版本、每项结果和失败时的脱敏错误码。协议返回的 token、AES key、签名 URL 和验证码不得写入验收记录。

## 2026-11-10 验收记录

测试环境为 DSCode 1.6.1、真实 DeepSeek Agent 和新建的临时 DSCode home、workspace，协议参考 `Tencent/openclaw-weixin@0ad1ae9`。手机微信的具体版本未记录。

| 项目 | 结果与证据 |
| --- | --- |
| 扫码登录 | 成功，owner/account/token 均存在，私有凭据权限为 0600；本次手机未要求 PIN，PIN 分支由自动化覆盖 |
| 文本 | 手机收到 `WECHAT_TEXT_OK` |
| 语音转写 | 手机语音产生正常文本 Turn，并收到转写指令的回复 |
| 多图 | 一次发送两张不同图片，只产生一条结果，用户确认两张均识别正确 |
| 图片与文件出站 | 用户同时收到生成的 report.txt 和第一张原图 |
| 文件入站 | 从“＋ → 文件 → 聊天中的文件”选择 report.txt 发送成功；服务端下载字节与原报告完全一致，Agent 完成处理并回复 |
| 重启后引用 | 首次暴露嵌套 message_item.msg_id 兼容缺失，补齐并加入回归测试后，重启再次引用同一条旧图成功，用户确认是第一张图 |
| 定时与 token 恢复 | 微信创建 90 秒后执行的 source 任务，确认创建后重启服务；期间无新微信输入，用户仍收到 `WECHAT_SCHEDULE_OK`；状态为 completed/delivered，attempt=1 |
| busy 与中止 | 长任务期间新请求收到 busy；通过真实 HTTP abort 接口中止原 Turn，返回 202，用户随后收到“本次处理已中止” |
| 故障和崩溃边界 | 自动化覆盖附件整批拒绝、API 错误/超时、持久化失败、未知引用、已提交不重跑、无持久化 outbox、部分发送重试及失败通知 |

手机的“转发”选择列表没有机器人，但会话内文件入口可以发送。[上游 issue #198](https://github.com/Tencent/openclaw-weixin/issues/198) 也记录了转发目标不可见的反馈。

测试服务已停止，临时私有夹具保留。维护者可通过 `node scripts/wechat-live.mjs <fixture-root>` 恢复显式准备的隔离夹具；根目录需包含 server.json、home 和 workspace，脚本复用现有 scheduled-tasks 指南并支持优雅关闭。
